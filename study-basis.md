# Study basis / Bases de estudio

## Question

What information is required to build an auditable loading-system process study?

| Area | Required evidence | Status |
| --- | --- | --- |
| Composition and properties | Approved composition, phase and property basis | Not provided |
| Pipe geometry | Internal diameter, schedule, length, elevation, fittings | Synthetic example only |
| Source and destination | Verified equipment boundaries and allowable conditions | Not provided |
| Steady-state model | Mass/energy balances, hydraulic model, model checks | Not performed |
| Transient behavior | Defined scenarios and specialist validation | Not performed |
| Safeguards | Approved P&ID, cause/effect, relief and hazard studies | Outside this prototype |

## Calculation record

Record input source, units, revision, calculation owner, independent check and assumption sensitivity. An input with no verified source stays an assumption.

## Proposed next deliverables

1. A reviewed basis of design with a clear battery limit.
2. An independently checked model and mass/energy closure report.
3. A sensitivity report with uncertainty and limitations.

Only the straight-pipe geometry example exists in this initial repository.
